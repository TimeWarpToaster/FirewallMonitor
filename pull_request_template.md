Currently, contributing is isolated to myself, but I Try to adhere to the following guidelines when managing sources:

- [ ] Provide a collection of executables, prepared to run out-of-the box, based on the current sources.
    - [ ] Provide a default settings file, configured with common decency, and external actions disabled (e.g. firewall management).
- [ ] Provide sources matching the executables.
- [ ] Provide instructions and documentation that is current, coherent, and can be followed from begining-to-end, with either the executables or built sources.
    - [ ] ReadMe
        - [ ] Getting Started
        - [ ] Configuring
    - [ ] Check that and supplemental How-To's are still workable.
     

Branches are not currently a thing, but may begin to be with the next release of software.
