# Security Policy
 
## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x   | :x: |
| 3.x   | :white_check_mark: |
| 4.x   | :white_check_mark: |

## Reporting a Vulnerability

This application is intended to run predominantly in an already secure
setting. That said, if you do find what you consider to be a security 
vulnerability, please make report to:

buzyngb@gmail.com

Any specific information you can provide, would be appreciated.

I have been working on this project alone, so I apologize in advance 
for any delay in response.
